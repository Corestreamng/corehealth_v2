# Release v2.6.0.73

**Date**: 2026-11-24  
**Git Tag**: `v2.6.0.73`  
**Domain**: Accounting (cost of goods issued, pharmacy returns, finance modules), Store masters and governance, native staff app, release sync of every component  

---

## Overview

This release books the cost of stock when it is used (not when it is bought), corrects how a pharmacy return is accounted, and brings the Store masters, Store Governance and the finance modules of the Accountant section into the native staff app. It is also the first release in which every changed component carries the core tag.

## Key changes

1. **Cost of goods issued** (perpetual inventory): stock issued to a patient posts `DR 5010/5020 cost of sales / CR 1300/1310/1320 inventory` at the batch cost, once (`StockDispenseCostObserver`, `InventoryCostService`). Purchases stay assets.
2. **Reversed entries counted correctly**: ledger balance queries count a reversed original together with its reversal (`JournalEntry::LEDGER_STATUSES`); before, a reversal subtracted the amount twice.
3. **Pharmacy returns**: approval reverses the sale (`DR 4020 revenue / CR patient deposits`, AR-HMO for the HMO part) and, for restocked goods, restores their cost (`DR 1300 / CR 5010`). A damaged return puts nothing back in inventory.
4. **Backlog migrations** (reversible, idempotent):
   - `2026_11_25_100000` posts the missing cost of goods issued (one entry per month and inventory account) and trues up opening stock the ledger never received.
   - `2026_11_25_110000` corrects the entries the old rule booked for pharmacy returns (one per return).
   - Command `php artisan accounting:backfill-inventory-cost` previews by default; `--apply`, `--no-true-up`, `--rollback`. Set `INVENTORY_BACKFILL_ON_MIGRATE=false` to skip both migrations.
   - **Cost data guard:** both migrations skip and log, and the command warns, when the backlog cost is larger than all income booked (batch cost prices need checking first).
5. **Native staff app 1.1.0+2**:
   - Store: Stores, Products, Categories, Suppliers, Store Governance, Expenses, draft PO edit; the Pharmacy section's Stores, Products and Categories.
   - Accounting: fixed assets, capex, liabilities, leases, statutory remittances, budgets (with lines), cash-flow forecast (period items, patterns), cost centres (budgets, allocations), KPIs (edit, history, alerts), banks, bank reconciliation (matching, statement files), opening balances, saved report filters, PDF and Excel downloads.
6. **Server surface**: `mobile/store/{masters,governance,expenses}`, `mobile/pharmacy/masters`, `mobile/accounting/*` for the modules above. Web controllers that returned Blade answer JSON on request; redirect-with-flash answers become JSON through the `mobile.json` middleware.
7. **Web fixes found on the way**: Statutory Remittances queried `banks.active`; Opening Balances sorted by `account_code`; saved report filters could not be saved or loaded; reconciliation list showed no bank; adding a statement line without a reference crashed; Budgets and Cash-flow lists crashed without `search[value]`; cost-centre budget without a note crashed; the liabilities export joined a missing `vendors` table; the cost-centre Excel export called two missing helpers; the reconciliation PDF had no view; routes pointing at missing reconciliation methods were removed.
8. **Web guards**: write routes of Stores, Products, Categories (SUPERADMIN, ADMIN, STORE, PHARMACIST) and Suppliers (SUPERADMIN, ADMIN, STORE, ACCOUNTS) are role guarded; reads are unchanged.

## Upgrade notes
1. `php artisan migrate`. On a database where batch cost prices look unreliable the two accounting migrations log and skip; preview with `php artisan accounting:backfill-inventory-cost`, check the costs, then run it with `--apply`.
2. The opening-stock true-up books stock the ledger never received to retained earnings (`3100`). Have finance review the amount in the preview before applying.
3. `php artisan route:cache` if `bootstrap/cache/routes-v7.php` exists.
