## Overview

Release `v2.6.0.65` modernizes the hospital landing page with dynamic co-branding and eliminates doctor consultation encounter memory leaks.

## Key Enhancements
1. **Modern Welcome Landing Page**:
   - Dynamic co-branding using `site_name`, `logo`, and `--hospital-primary`.
   - Demo mode isolation via `application_status.show_branded_homepage` and preview query flags `?branded=0` and `?demo=1`.
2. **Encounter Memory Optimization**:
   - Destroyed lingering Select2 remote instances and unpinned DOM event listeners during encounter transitions.
   - Refactored rapid procedure catalog queries.
