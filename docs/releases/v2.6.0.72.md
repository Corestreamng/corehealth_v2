## Overview

Release `v2.6.0.72` enhances the **HMO Tariff Overrides Engine**, resolving a critical scope-matching omission for global catalog overrides (`All Products` / `All Services`) and adding direct **Coverage Mode Interception** (`express`, `primary`, `secondary`, or `inherit`). Hospital administrators and HMO executives can now enforce both custom copay structures (e.g. 0% patient copay) and the exact validation workflow (immediate auto-approval vs desk validation vs pre-authorization code requirement) in a single unified rule.

## Key Enhancements

1. **Global Catalog Scope Resolution (`all_products` & `all_services`)**:
   - Resolved the query omission in [`HmoHelper::getTariffOverrideData()`](file:///home/mrapollos/Documents/work/corehealth_v2/app/Helpers/HmoHelper.php#L170-L195) where `target_type = 'all_products'` and `all_services` were bypassed during billing calculations.
   - Introduced a 6-tier mathematical specificity hierarchy:
     1. Exact HMO + Specific Item (Score: 15)
     2. Exact HMO + Item Category (Score: 13)
     3. Exact HMO + All Products/Services (Score: 11)
     4. Scheme + Specific Item (Score: 5)
     5. Scheme + Item Category (Score: 3)
     6. Scheme + All Products/Services (Score: 1)

2. **Explicit Coverage Mode Interception (`coverage_mode`)**:
   - Added `coverage_mode` enum (`express`, `primary`, `secondary`, `null`) to the `tariff_overrides` table via migration [`2026_11_13_120000_add_coverage_mode_to_tariff_overrides_table.php`](file:///home/mrapollos/Documents/work/corehealth_v2/database/migrations/2026_11_13_120000_add_coverage_mode_to_tariff_overrides_table.php).
   - **Explicit Mode Override**: When specified, the override dictates the bill request's coverage mode and validation status (`express` &rarr; `approved`, `primary`/`secondary` &rarr; `pending`).
   - **Inherit from Underlying Tariff (Default / Null)**: If left blank, the request smoothly inherits the underlying `HmoTariff.coverage_mode` configured for that specific product or service, falling back to `express` if unlisted.

3. **Management UI & Live Preview Synchronization**:
   - **Overrides DataTable**: Added a dedicated `Coverage Mode` column rendering colored status badges (`Express`, `Primary`, `Secondary`, or `Inherit Tariff`).
   - **Add Override Modal**: Added an intuitive Coverage Mode selector in the pricing rule step with helpful helper text.
   - **Live Preview Engine**: Dynamic sidebar story automatically updates to describe both the copay split and the authorization workflow in real time.

4. **Automated Feature Verification**:
   - Added comprehensive feature test suite [`tests/Feature/HMO/TariffOverrideTest.php`](file:///home/mrapollos/Documents/work/corehealth_v2/tests/Feature/HMO/TariffOverrideTest.php) verifying Scheme-level `All Products` 0% copay overrides, explicit `secondary` mode enforcement, tariff mode inheritance, specific item priority over global rules, and API endpoints.
